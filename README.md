# Hippo Procurement — Landing Page

Marketing website for **Hippo Procurement Ltd**, a West African trade facilitation company that helps pharmacies, clinics, and SMEs source medical and high-demand products directly from factories — 25–40% cheaper, delivered in 10–25 days.

## What This Site Does

Single-page conversion site targeting decision-makers (pharmacy owners, clinic procurement leads, wholesale traders). Everything drives to one action: WhatsApp chat.

Core value proposition: **Cheaper stock. Faster delivery. No middlemen.**

## Stack

- **Next.js 16** (App Router)
- **Tailwind CSS**
- **TypeScript**
- **pnpm**


WhatsApp CTA links to the Hippo business number. All conversion happens off-site via WhatsApp — no forms, no email capture.
